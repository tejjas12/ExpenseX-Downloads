ExpenseX — Personal Expense Tracker

Take Control of Your Money. Track Every Rupee.

ExpenseX is a simple and user-friendly Android application designed to help users manage their personal finances. Track income, monitor expenses, manage monthly budgets, and understand your spending habits — all in one place.

✨ Features

- Income Tracking — Record and manage your monthly income.
- Expense Tracking — Add and manage daily transactions.
- Budget Management — Set monthly and category-wise budgets.
- Expense Analytics — Visualize your spending patterns.
- Category-wise Analysis — Understand where your money goes.
- CSV Export — Export your transaction history.
- Local Data Storage — Keep your financial records stored on your device.
- Budget Alerts — Get alerts when spending reaches budget thresholds.

🛠️ Built With

- Kotlin
- Jetpack Compose
- Android Studio
- Room Database
- Material Design

📲 Installation

1. Open the Download link above.
2. Download the latest "ExpenseX.apk" file.
3. Open the downloaded APK on your Android device.
4. Allow installation from this source if Android asks.
5. Tap Install and start using ExpenseX.

🔒 Privacy

ExpenseX stores transaction information locally on the device. It does not currently provide cloud synchronization between devices.
